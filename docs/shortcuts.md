# 快捷键规范

基于调研报告 §11 整理。原报告把 `⌘I` 同时分给「插入行 / 复制过滤规则 / 格式化 SQL」，`⌘⇧F` 同时分给
「聚焦对象树过滤框 / 格式化 SQL」，且 Windows/Linux 只是把 ⌘ 机械替换为 Ctrl。这里按**焦点上下文**重新分配：
同一组合键允许出现在不同上下文，**同一上下文内不得重复**。落地时对应 GPUI 的 `key_context`。

约定：⌘=Cmd，⌃=Control，⌥=Option，⇧=Shift。Win/Linux 列只写与「⌘→Ctrl」不同的项。

> **实现状态**：数据网格的 `⌘S`（提交）、`⌘⌥P`（预览 SQL，M8 前是 `⌘⇧P`）、`⌘Z` / `⌘⇧Z`、`⌘I`（插入行）、`⌘D`（克隆行）、`⌘⌫`（标记删除 / 恢复）、`Enter`（开始编辑）、直接键入（开始编辑）与单元格编辑框内的 `Tab` / `⇧Tab` / `Enter` / `Esc` 已实现。已实现 `⌘P`、`⌘K`（网络型连接切换数据库）、`⌘⇧P`（命令面板，M8）、`⌘W`、`⌘1`–`⌘9`（第 1–9 个标签）、`⌘B`、`⌘R`（刷新对象树）、`⌘F`（过滤抽屉）、`⌘C`（复制选区）、`⌘[` / `⌘]` / `Ctrl+Tab`，启动页 `⌘N`（新建连接）与上下 / 回车；查询标签的 `⌘T`（新建查询）、`⌘Y`（查询历史）与编辑器焦点内的 `⌘Return` / `⌘⇧Return` / `⌘.`；网格的 `Space`（行详情检查器，Text / JSON 模式）；查询结果网格的 `Enter`（开始编辑，仅单表且有主键的结果集）与 `⌘S`（提交结果暂存）；`Escape` 逐级退出（M8，见下）。工具栏四个原来只有按钮的操作也有了键与命令面板入口（M8）：`⌘⇧A`（审计日志）、`⌘⇧M`（切换安全模式）、`⌘⇧T`（切换主题）、`⌘⇧D`（切换详情面板）；工具栏与标签栏的图标按钮提示改为中英文。其余为规划。绑定集中在 `crates/fg-app/src/views/actions.rs`，编辑器上下文常量是 `EDITOR_CONTEXT`（GPUI Kit 在编辑器元素上压入 `Input mode=editor`，绑定谓词写作 `Input && mode == editor`）。

## 命令面板

`⌘⇧P` 打开，按名字搜工作区命令，回车执行；面板会显示每条命令自己的快捷键。
目前只列工作区级命令（跳转、切换、新建 / 关闭标签、侧栏、历史、片段、刷新、过滤、
导出、导入）：确认时会从面板 overlay 派发 action，冒泡到工作区视图，所以网格与编辑器
专属的动作（提交、撤销、插入行、运行语句等）不在此列——它们仍走自己的按键，面板够不着
它们所在的分支。网格的 SQL 预览因此从 `⌘⇧P` 让位到 `⌘⌥P`。

## Escape 逐级退出

M8 已实现工作区级的逐级退出（`DismissTopmost`，`Workspace` 上下文；更深的上下文——单元格编辑器、
历史面板、片段面板——仍有自己的 `Escape` 绑定并优先触发）。按一次只关最顶上一层，关完
一层再按才关下一层；永远不关标签、不退出应用：

1. 命令面板（`⌘⇧P`）→ 关面板（面板输入框获得焦点时，面板自己的取消先触发，效果相同）
2. Quick Open（`⌘P`）→ 关面板，不打开任何表
3. 数据库切换器（`⌘K`）→ 关面板
4. 导出 / 导入向导 → 关向导，不执行
5. 历史 / 片段 / 审计面板 → 关面板
6. 当前标签的过滤抽屉（仅表标签打开时）→ 收起抽屉
7. 关标签确认横幅 → 取消关闭（脏标签保持原样）

行内编辑与查询取消不在此列，仍走原来的路：编辑中的 `Escape` 先取消编辑（单元格编辑器
上下文更深，优先），运行中的查询仍用 `⌘.` 取消——`Escape` 在 GPUI Kit 的编辑器上下文里
已有用途（收起查找 / 替换浮层），抢掉它会让 `⌘F` 之后退不出来。行详情与多选清空仍是
规划，未接入本顺序。

> 注意：M8 之前本表曾列出「切换连接 `⌘⇧K`」，但代码里从未有过这个绑定（`⌘⇧K` 一直是
> 「把当前语句存为片段」），M8 定稿时已删掉该行，不再留幽灵条目。

## 已知需要再确认的点

- `⌘[` / `⌘]` 与编辑器的缩进快捷键在 `editor` 上下文内冲突：编辑器内缩进使用 `Tab` / `Shift+Tab`，标签切换保持全局。**已实测到的表现**：焦点在编辑器时 `⌘[` / `⌘]` 走库里的块缩进，不切标签；焦点在网格或侧栏时仍切标签。
- `⌘.` 原本是 GPUI Kit 编辑器上下文的「code actions」。fastgrid 还没有 code actions，先挪给「取消查询」；将来要做的时候另找键，别再抢回来。
- `⌘F` 在编辑器里是库自带的查找 / 替换（不是过滤抽屉）；过滤抽屉的 `⌘F` 只在网格上下文生效。同一组合键在不同上下文含义不同，是本文件的既定规则。
- Win/Linux 的 `Ctrl+K`、`Ctrl+B` 与部分输入法或终端习惯可能冲突，需要三端实机验证后调整。
- 所有快捷键必须可在设置中重绑定（M8），并在命令面板中可搜索到。
