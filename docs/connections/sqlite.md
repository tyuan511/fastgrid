# SQLite 连接指南

SQLite 是内嵌引擎：没有服务器，连接就是一个文件路径。

## 表单字段

- **路径**：数据库文件的完整路径。文件不存在时按 SQLite
  的语义处理（打开即创建空库，写第一笔数据后落盘）。
- **`:memory:`**：纯内存库，适合临时查看或复现问题；
  连接关闭即消失，不要把它当持久存储用。

## 行为说明

- SQLite 支持完整的结构编辑：改列、索引、外键时如果涉及
  SQLite 本身不支持的原地修改，fastgrid 会展开成“建新表、
  拷数据、删旧表、改名”的重建，触发器原文保留；
  结构预览里会标出 `via table rebuild`。
- 只读查看：把连接的安全模式设为 ReadOnly，写操作会被
  策略层直接拒绝，不会落到引擎。
- SQLite 没有“数据库”与“命名空间”的区分：对象树里直接
  是表、视图、索引、触发器。
